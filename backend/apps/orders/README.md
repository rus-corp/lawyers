# Режим выдачи документов

По умолчанию оплата выключена (`PAYMENTS_ENABLED=false`). Форма отправляет email и ID документа в `POST /api/orders/`; сервер проверяет файл и ставит отправку документа и инструкций в Celery. Ответ 202 означает постановку в очередь, а не подтверждённую доставку письма. Бесплатные запросы не создают платёжных заказов.

Для возврата оплаты добавьте `PAYMENTS_ENABLED=true` в `backend/.env` и пересоздайте API и worker. Интерфейс читает режим из `GET /api/orders/config/`; отдельной настройки фронтенда нет. Цены, интеграция ЮKassa и обработчик подтверждения ранее созданных платежей сохранены.

Для отправки необходимы работающие Redis, Celery worker и SMTP. При обновлении пересоберите также worker: его код находится в Docker-образе. Например: `docker compose up -d --build api worker web`.

Тексты боковой панели могут задаваться в админке: проверьте индивидуальные формулировки об оплате. Название кнопки «Оплатить документ» автоматически заменяется в бесплатном режиме.
